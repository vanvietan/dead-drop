description=Each eligible building has a fixed 100% chance to receive one machine. Pick it up and place it anywhere, or right-click it in the store to open a crate and receive a server-selected reward after the item reel finishes.
description=
description=Supports Project Zomboid Build 42, multiplayer server validation, configurable rarity chances and reward pools, free debug orders, and optional items from other Workshop mods.
description=
description=[h1]Admin Configuration[/h1]
description=Server admins can replace the reward pool for each rarity from the LootBox Sandbox Options. Leave an item-pool field blank to keep its default vanilla rewards.
description=
description=Use Script FullTypes in this format: [code]Module.Item:Quantity;OtherMod.Item:Quantity[/code]
description=Example: [code]Base.Axe:1;Brita.AR15:2[/code]
description=The Brita entry above only demonstrates the format and may not be the real item ID in your installed version. Always verify the Script FullType in the source mod's [code]media/scripts[/code] files. Combine the name after [code]module[/code] with the name after [code]item[/code]: for example, [code]module Base[/code] and [code]item Axe[/code] become [code]Base.Axe[/code].
description=On a typical Steam installation, downloaded mod files are under [code]Steam/steamapps/workshop/content/108600/<WorkshopID>/[/code]. Search that mod folder for [code]media/scripts[/code] and open its .txt files.
description=
description=Quantities must be whole numbers from 1 to 100. Invalid or unavailable entries are ignored. If a custom pool contains no valid items, LootBox falls back to that rarity's default pool. Repeat an entry to give it additional equal-probability slots.
description=
description=For rewards from another Workshop mod, install and enable that mod on the server and every client. Add its Mod ID to [code]Mods=[/code] and its Workshop ID to [code]WorkshopItems=[/code]. LootBox uses the item's Script FullType, not its Workshop ID, and does not require optional reward mods automatically.
